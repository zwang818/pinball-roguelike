# MODULES · 系统分工

> 状态：作业 MVP / 最后更新：2026-09-26 / 版本：轻量 Bible v0.2

## 模块速查

| 模块 | 职责 | 输入 / 输出 | 依赖边界 |
|---|---|---|---|
| 游戏流程 | 管理两关顺序、独立关卡分数、总分、倒计时、成功、失败和整局重置 | 输入关卡分数、球数、时间与活动弹珠状态；输出关卡状态与页面切换 | 超时或球数耗尽时等待最后一球结算；不直接控制弹珠物理 |
| 瞄准与发射 | 根据鼠标位置瞄准，按住左键蓄力并在松开时发射一颗弹珠 | 输入鼠标方向与蓄力时长；输出一次发射并立即扣除 1 颗球 | 使用弹珠模板，不负责计分和关卡判定；超时后禁止发射 |
| 弹珠物理 | 承担重力、碰撞、反弹、落底和单球生命周期 | 输入发射方向与强度；输出唯一落点结果或无效落点 | 与图钉、边界和落点区域交互，不从图钉碰撞获得分数 |
| 图钉与边界 | 提供两关不同的固定障碍布局、稳定反弹表面和合理可达路径 | 输入当前关卡；输出对应布局及物理碰撞 | Floor 不得阻挡计分区；五个区域都须可达；本模块不计算分数 |
| 落点计分 | 识别弹珠最终区域并产生一次正分、负分或 0 分结果 | 输入弹珠落点与 Buff；输出四舍五入后的本球整数分值 | 飞出边界或未进区域记 0 分；结果交给游戏流程 |
| Buff 选择 | 第一关成功后提供三选一，并在第二关应用唯一效果 | 输入第一关通关；输出所选 Buff | 只影响第二关球数或计分规则，不叠加多个 Buff |
| HUD 与结果页面 | 展示关卡分数、目标、球数、倒计时警告、Buff、胜利与失败信息 | 输入当前游戏状态；输出红色十秒警告、时间耗尽提示、成绩和重试选择 | Buff 与结果页面暂停计时；只展示和转交选择，不自行修改规则 |

## 协作关系

瞄准与发射 → 弹珠物理 → 图钉与边界 → 落点计分 → 游戏流程 → Buff 选择／结果页面

游戏流程持续向 HUD 提供当前关卡、分数、目标、剩余球数和倒计时。

## 当前工程事实

- 主场景为 `scenes/Main.tscn`，现有基础包括弹珠、发射器、图钉阵、地板和边界。
- 弹珠是 `RigidBody2D`；地板与边界使用 `StaticBody2D`。
- 当前白盒图钉阵由 `PegBoard` 承载，后续只需让它能根据关卡切换布局。
- 现有 Floor 需要为底部五个计分区让位，并以全部区域均有合理命中机会为调试目标。
- 所有新增功能必须保持参数可调，且不得破坏现有基础碰撞与反弹。

## 系统边界

- 模块之间只交换方向、力度、落点分值、球数、时间、关卡状态和 Buff 结果。
- 任何模块都不能绕过游戏流程直接宣布通关或失败。
- UI 不承载隐藏规则；玩家看到的数字必须与实际判定一致。
- 第二关开始时关卡分数归零，第一关分数仅由游戏流程保留用于通关总分。
- Buff 与结果页面不消耗关卡时间；整局重来必须清除分数、Buff、球数、计时和活动弹珠。
- 本项目模块数保持在 8 个以内；若超过或本文超过两屏，再考虑升级为模块化 Bible。

# 功能优先级清单

- **P0**：不做这个就不是这个游戏。
- **P1**：做了这个核心乐趣才完整。
- **P2**：做了能让游戏更耐玩。
- **P3**：做了能让游戏更“高级”，但删掉不影响核心。

| 功能名 | 优先级 | 一句话理由 |
|---|---|---|
| 瞄准方向控制 | P0 | 没有瞄准就不存在“选择这一发怎么打”的核心决策。 |
| 蓄力与力度反馈 | P0 | 蓄力让发射从简单点击变成可判断、可掌握的操作。 |
| 发射与球数消耗 | P0 | 每次发射必须消耗有限资源，才能产生风险与期待。 |
| 稳定可信的弹珠物理 | P0 | 碰撞、反弹和重力决定了“看球弹”的基本乐趣。 |
| 图钉与边界碰撞 | P0 | 它们构成弹珠运动的不确定性和主要观看过程。 |
| 袋洞／落点区域 | P0 | 没有明确落点结果，就没有“进不进袋洞”的悬念。 |
| 袋洞结果判定 | P0 | 球进入不同区域后必须产生清晰且确定的结算。 |
| 球数保留、增加与损失 | P0 | “能否继续发射”是每一球最直接的生存压力。 |
| 当前球数显示 | P0 | 玩家必须随时知道还剩多少次机会。 |
| 单球生命周期与清理 | P0 | 每颗球必须有发射、运动、结算、移除的完整闭环。 |
| 回合开始与结束 | P0 | 游戏需要判断何时继续、何时获胜或因无球而失败。 |
| 基础肉鸽升级选择 | P0 | 没有局内随机成长，它就只是弹珠机而不是弹珠肉鸽。 |
| 一局重新开始 | P0 | 失败后立即再来一局是核心循环的一部分。 |
| 袋洞奖励差异 | P1 | 不同落点价值不同，瞄准才会真正产生策略。 |
| 分数／伤害／目标进度 | P1 | 玩家需要知道每一球是否推动了当前目标。 |
| 发射轨迹预览 | P1 | 提供基础可控性，同时保留碰撞后的不确定性。 |
| 清晰的入袋反馈 | P1 | 动画、音效和数字反馈决定进袋是否令人满足。 |
| 碰撞反馈 | P1 | 图钉闪光、音效和轻微震动能显著强化连续弹跳快感。 |
| 连击或连续碰撞奖励 | P1 | 让复杂弹跳过程本身具有价值，而不只看最终落点。 |
| 基础升级池 | P1 | 需要覆盖球数、弹性、尺寸、力度、奖励倍率等不同成长方向。 |
| 升级三选一 | P1 | 有限选择让每局形成构筑，而不是被动获得数值。 |
| 关卡目标递增 | P1 | 每轮提高目标，才能检验当前构筑是否足够强。 |
| 局内状态界面 | P1 | 球数、目标、分数和当前效果必须能被快速读懂。 |
| 快速结算与继续按钮 | P1 | 减少等待，让“再来一发”的冲动不中断。 |
| 特殊袋洞 | P2 | 倍率、返球、复制球等袋洞能增加风险收益判断。 |
| 特殊图钉 | P2 | 爆炸、传送、倍率和一次性图钉可改变每局打法。 |
| 多球与分裂球 | P2 | 多球能制造强烈爽点，并形成鲜明构筑方向。 |
| 遗物／被动效果系统 | P2 | 跨回合组合效果能提升构筑深度和重复游玩价值。 |
| 商店与刷新机制 | P2 | 为资源分配和构筑修正增加长期决策。 |
| 多种球类型 | P2 | 重球、弹力球、穿透球等可以形成不同物理流派。 |
| 多种图钉阵布局 | P2 | 布局变化能避免每局瞄准方案完全相同。 |
| 普通关、精英关与 Boss | P2 | 不同压力测试可以检验并区分不同构筑。 |
| 随机事件 | P2 | 提供升级之外的风险、交易和局势变化。 |
| 路线选择 | P2 | 让玩家在奖励、风险和构筑需求之间做宏观决策。 |
| 难度递增与平衡曲线 | P2 | 保证成长不会迅速失去挑战，也不会过早卡死。 |
| 局外解锁 | P2 | 新球、遗物和关卡解锁能够支持长期目标。 |
| 每日种子／挑战模式 | P2 | 固定条件提供额外重玩理由和可比较性。 |
| 完整音效与音乐层次 | P3 | 能提升氛围和爽感，但不会改变核心玩法结构。 |
| 镜头震动与慢动作 | P3 | 可强化关键碰撞和高价值入袋的戏剧性。 |
| 高质量粒子和过场动画 | P3 | 提升观感，但白盒表现也能承载完整核心循环。 |
| 主题美术与角色包装 | P3 | 能建立辨识度，但不决定玩法是否成立。 |
| 剧情与世界观 | P3 | 提供情感包装，移除后核心游戏仍然完整。 |
| 图鉴与收藏系统 | P3 | 适合长期展示和收集，不影响单局循环。 |
| 成就系统 | P3 | 提供额外目标，但不是核心成长结构。 |
| 排行榜与社交分享 | P3 | 增加竞争和传播价值，但不影响单人核心体验。 |
| 自定义外观 | P3 | 提高个性化和商业化空间，不改变玩法。 |
| 回放与精彩时刻保存 | P3 | 方便展示罕见弹跳过程，但不是核心体验必需。 |

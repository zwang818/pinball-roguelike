# 核心循环

玩家判断袋洞收益并选择方向与力度，发射有限的弹珠，观看碰撞与入袋结果，再根据球数和奖励决定下一发，直至达成目标或耗尽球数。

瞄准 → 蓄力 → 发射 → 看球弹 → 看进袋洞 → 看球数变化 → 想再来一发 →（回到瞄准）

- **瞄准**：瞄准方向控制、发射轨迹预览。
- **蓄力**：蓄力与力度反馈。
- **发射**：发射与球数消耗、单球生命周期与清理。
- **看球弹**：稳定可信的弹珠物理、图钉与边界碰撞、碰撞反馈。
- **看进袋洞**：袋洞／落点区域、袋洞结果判定、清晰的入袋反馈。
- **看球数变化**：球数保留、增加与损失、当前球数显示。
- **想再来一发**：快速结算与继续按钮、回合开始与结束、一局重新开始。
